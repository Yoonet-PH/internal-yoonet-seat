Setting up a Yoonet seat

Ubuntu 24.04 LTS on a ThinkPad or desktop. About 40 minutes per machine, mostly waiting.
You need
The laptop or desktop, its charger, a USB stick of 8GB or more, wired or WiFi internet, and the person's name and email for their account.
Before wiping
Copy the person's Documents, Desktop and Downloads to Google Drive. Ask if they use anything that only runs on Windows. Windows can always be put back; the licence lives in the machine.

1. Make the install stick (once, reuse it for every machine)

  1. Download Ubuntu 24.04 LTS Desktop from ubuntu.com/download/desktop.
  2. On Windows: open Rufus (rufus.ie), pick the stick and the ISO, press Start, accept the defaults. On a Mac: run tools/make-usb.sh from the repo.

2. Boot from the stick

  1. Plug the stick in, power on, and tap F12 (ThinkPad) or F11 / Del (desktop) for the boot menu. Choose the USB entry that starts with UEFI.
  2. If it boots to Windows instead: enter BIOS with F1 (ThinkPad) or Del (desktop), find Security, and turn Secure Boot off if Ubuntu refused to start. Usually it is not needed.

3. Install Ubuntu

  1. Choose Install Ubuntu, English, your keyboard, connect to WiFi.
  2. Pick Default installation, and tick Install third-party software and Download and install support for additional media formats.
  3. Choose Erase disk and install Ubuntu. This removes Windows.
  4. Name: the person's full name. Computer name: yoonet-firstname. Username: their first name. Password: something they choose; they type it to install things. Leave Require password to log in on.
  5. Install, restart, remove the stick when asked, log in.

4. Run the seat script

  1. Open a terminal with Ctrl + Alt + T and paste:
curl -fsSL https://raw.githubusercontent.com/Yoonet-PH/internal-yoonet-seat/main/setup.sh | bash
  1. It asks for the password once, then runs for 10 to 15 minutes and ends with a green Done block. If it stops early, run the same line again; it picks up where it left off.

5. Hand over to the person (they do this, at their desk)

claude                      # sign in with the Anthropic account
gh auth login               # GitHub, choose HTTPS and the browser
git config --global user.name "Their Name"
git config --global user.email their.name@yoonet.io

Then sign into Chrome with their Yoonet Google account. Gmail, Drive, Slack and Zoom all run in the browser or from the Ubuntu App Center.

Checklist per machine

  • Files backed up to Drive, no Windows-only tools needed
  • Ubuntu installed, logs in, WiFi connects
  • Seat script finished with the green Done block
  • Headset, webcam and monitors plugged in and working (Settings, Sound and Displays)
  • Person signed into Claude Code, GitHub, Chrome
  • yoonet-doctor runs and shows no errors under Recent errors

If something goes wrong

SymptomDo this
Anything at all after setupOpen a terminal: yoonet-doctor | claude "here is my seat report. <what is wrong>" and follow Claude Code through the fix.
Stick will not bootTry the other USB port, then rebuild the stick. On a ThinkPad check Secure Boot in BIOS.
No WiFi during installPlug in a cable or a phone on USB tethering for the install; WiFi drivers arrive with the updates.
Screen stays black after installHold the power button, boot again. If it repeats, hold Shift at boot, choose Advanced, then the recovery entry, and run the seat script from there.
Need Windows backDownload the Windows 11 media tool on another PC, make a stick, install. The licence activates by itself.
